## Notas para construirlo
- Cada grupo de luz va en su propio circuito: repisas, listones y panel, halo del TV, escritorio.
- LED blanco neutro-cálido (3500–4000 K) en todas las tiras, con perfil de aluminio y tapa opal para que no se vean puntos.
- Con un LG OLED (sin Ambilight propio) el halo se hace con una caja HDMI de sincronización. Con la serie C hay que dejar ≈3–4 cm entre el TV y el panel.
- La barra de sonido del render mide ≈84 cm y es solo una referencia: una barra potente mide 1–1,2 m y cabe bajo el TV.
- Deja resueltos cables y tomas antes de instalar listones y repisas.

> Las medidas son aproximadas, calculadas desde la foto y el video. Mide antes de comprar.
